# Aatish Chaudhary portfolio
Static site (HTML, CSS, JS) for GitHub Pages. Upload every file, keeping the `assets/` folder next to the HTML pages.

- Styles: `assets/css/portfolio.css`; scripts and shared nav/footer: `assets/js/portfolio.js` (edit `PAGES` to change the menu).
- Theme: light/dark, saved in localStorage.
- New project: copy `project-enterprise-api-system.html`, edit the text, add a card in `index.html` and `projects.html` (list tags in `data-tags`), add the URL to `sitemap.xml` and `llms.txt`.
- Add a CV: place the PDF in the repo and link it from `resume.html`.
- SEO: JSON-LD is in each page head; keep the FAQ on the home page in sync with its FAQPage JSON-LD.
