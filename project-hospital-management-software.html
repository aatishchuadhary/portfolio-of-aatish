Hospital Management Software

A software solution intended to support hospital administration and healthcare operational workflows.

Overview

Hospital Management Software is a software solution intended to support hospital administration and healthcare operational workflows. Its own sign-up page describes it as healthcare management for patients, doctors and administrators.

The features below are limited to what the two screenshots show. Anything beyond that has not been documented yet, so it is not claimed.

Features

  • Account registration (create account) form with first and last name, email, date of birth, phone number and password
  • Dashboard with sidebar navigation, including schedule, profile and logout
  • Add Appointment form: department, doctor, date, mobile number and problem
  • Appointment list with per-row action buttons
  • Online payment dialog for appointments (Khalti checkout shown)
